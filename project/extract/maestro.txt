1. BRIEF EJECUTIVO PARA BASE44
El proyecto no consiste en construir una página estática que solamente muestre una valuación de Soriana. El objetivo es
reconstruir desde cero una herramienta reutilizable de valuación empresarial que se presente y se demuestre
inicialmente con Soriana.
La app debe comportarse como un sistema profesional de análisis financiero: Soriana es el caso preconfigurado, pero la
arquitectura, los inputs, las fórmulas y la interfaz deben permitir que posteriormente se sustituya la empresa, industria y
datos sin rehacer la aplicación.
La prioridad del proyecto es la interpretación y presentación de información, no añadir complejidad matemática
innecesaria. La matemática debe existir y ser consistente, pero debe quedar organizada detrás de una experiencia clara,
visual y progresiva.
La nueva versión debe partir de cero. La aplicación actual sirve como referencia funcional para entender qué hace el modelo
existente; no debe tomarse como plantilla visual ni como código base.
URL de referencia funcional:
https://app-valuacion-intrinseca-empresas.vercel.app/
Principios no negociables
l Soriana como caso de demostración: toda la experiencia inicial debe sentirse como una evaluación de Soriana.
l Arquitectura reutilizable: los datos de Soriana deben ser un conjunto de valores cargados, no una estructura rígida.
l Dos niveles de información: primero resultados e interpretación; después metodología, inputs, tablas y detalle.
l Diseño de producto: debe parecer una aplicación financiera construida por un equipo de desarrollo, no una hoja de
Excel convertida en página web.
l Información primero: dashboard, KPIs, visualizaciones y explicaciones breves antes que tablas extensas.
l Transparencia: cualquier resultado debe poder rastrearse hasta sus inputs y metodología.
l No mezclar actividades: las empresas comparables de la actividad de benchmarking no deben convertirse en parte del
producto final.

7. DIRECCIÓN UX/UI
La interfaz debe sentirse como un producto financiero moderno: limpia, jerárquica, rápida de leer, con microinteracciones y
navegación coherente.
Lenguaje visual
l Base neutra: blanco, gris muy claro, gris oscuro y azul institucional.
l Tec: azul institucional como color estructural para navegación, encabezados y elementos de identidad.
l Soriana: rojo, verde y amarillo únicamente como acentos de marca o estados específicos; evitar saturación.
l Cards con bordes suaves, sombras discretas y mucho espacio negativo.
l Tipografía sans-serif moderna y consistente.
l Números financieros grandes, con jerarquía clara entre cifra principal, unidad y explicación.
l Gráficas limpias, con pocos colores y leyendas directas.
l Tablas únicamente cuando sean necesarias para auditar datos; nunca como primer recurso.
l Diseño responsive para desktop y tablet; el dashboard debe seguir siendo legible en pantallas menores.
l Transiciones rápidas y discretas: entrada de páginas, cambio de tabs, expansión de detalles y actualización de KPIs.
Patrones de visualización recomendados
l KPI cards para valor intrínseco, precio de mercado, potencial, WACC y EV.
l Bullet/bar de valor intrínseco vs. precio actual.
l Waterfall para pasar de PV de FCF + PV de terminal a EV, deuda, efectivo y Equity Value.
l Line chart para ventas y FCF histórico/proyectado.

Usa este documento como material maestro de contexto y el Excel que se cargará aparte como fuente operativa de
datos. También inspecciona la aplicación anterior indicada en este documento para entender su funcionalidad.
Construye una aplicación nueva desde cero. No copies la apariencia de la aplicación anterior. Conserva lo útil de su lógica

El producto final debe verse como una aplicación financiera académica moderna, no como un spreadsheet. La complejidad
debe existir detrás de una interfaz progresiva: resultado → interpretación → detalle → inputs → metodología.

reutilizable para otra empresa e industria simplemente reemplazando el dataset y los parámetros.
Prioridad absoluta: exactitud de datos + trazabilidad + claridad + diseño + reutilización. No sacrificar legibilidad por
mostrar más información.
